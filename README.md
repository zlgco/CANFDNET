# CANFDNET

CAN FD(CAN with Flexible Data-rate)는 기존 CAN 버스를 확장한 최신 규격으로, 한 프레임에 최대 64바이트의 데이터를 실을 수 있으며 데이터 구간(Data Phase)에서 최대 5Mbps의 전송 속도를 지원합니다.
CANFDNET 시리즈는 고성능 산업용 이더넷–CAN(FD) 데이터 변환 장치입니다. 1~8개의 CAN(FD) 버스 인터페이스와 1개의 일반 이더넷 포트, 1개의 차량용 2선식(two-wire) 이더넷 포트를 탑재하고 있으며, 차량용 이더넷은 OPEN Alliance BroadR-Reach 규격을 충족합니다. 동작 온도 범위는 -40~85℃이고, CAN FD 최대 전송 속도는 5Mbps입니다. 이더넷 측에서는 TCP 서버, TCP 클라이언트, UDP 등 다양한 동작 모드를 지원합니다. 전용 설정 소프트웨어를 통해 각종 파라미터를 필요에 맞게 구성할 수 있고, 검증된 안정적인 TCP/IP 프로토콜 스택을 갖추고 있습니다. 덕분에 사용자는 CAN(FD) 네트워크와 이더넷 네트워크를 손쉽게 연동하여 CAN 버스 네트워크의 적용 범위를 한층 넓힐 수 있습니다.
